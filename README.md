# SOC Analyst Field Notes

Practical notes, playbooks, and queries from real SOC work.
Not a tutorial — built for analysts who want ready-to-use references.

## Who this is for
- Junior SOC analysts wanting structured references
- Anyone preparing for SOC interviews
- Blue teamers building detection logic

## Structure
- `playbooks/` — Step-by-step incident response guides
- `threat-hunting/` — Splunk, Elastic, and Sigma queries
- `alert-triage/` — False positive patterns and priority logic
- `tools-and-commands/` — Quick reference cheatsheets
- `case-studies/` — Sample incident timelines

## Tools Referenced
- Splunk, Elastic SIEM
- Wireshark, Nmap, Volatility
- Windows Event Viewer, Sysmon
- VirusTotal, Any.run, Shodan
